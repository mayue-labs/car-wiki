# 汽车品牌价位图谱

按代表车型和产品布局观察汽车品牌价位，覆盖全球主要市场的代表品牌与历史品牌。

**在线访问：[汽车品牌价位图谱](https://mayue-labs.github.io/car-wiki/)** · [GitHub 仓库](https://github.com/mayue-labs/car-wiki)

## 项目概况

面向桌面浏览器的单文件 HTML，现有 **171 个品牌 / 业务条目、8 个观察价位档、151 张分级卡片和 28 条历史 / 困境 / 区域退出档案**。其中 8 个条目同时出现在卡片和档案中。条目含子品牌、产品体系及区域合资业务，并非 171 家独立公司。

- 常驻价格目录展示各档数量，价格后用“·”分隔，随筛选同步更新。
- 支持品牌、英文名、车型搜索，以及经营状态、品牌起源和价位筛选。
- 每张卡片包含 Logo、英文名、国家和车型价格；点击信息图标查看定位说明，点击价格后的链接图标回查来源。
- 支持浅色、深色、跟随系统和返回顶部；可通过浏览器菜单打印。
- 数据、样式、交互与 Logo 均内嵌，离线可用；资料来源链接需要联网。

## 资料口径

初版整理于 **2026-11-14**，全球品牌增补核对和页面更新于 **2026-11-15**。报价、状态记录对应来源披露节点，后续变化请回查来源。

价位档是编者根据产品布局与代表车型做的观察归类，**不是品牌全系价格上下限，也不是销量加权均价**。同一品牌往往跨多档；数字只对应写明的车型、配置、年份与销售市场。历史价格不与现行报价直接比较。

海外保留原币，不按实时汇率换算中国售价，也不按外币数值与人民币排序。海外分档按产品布局观察；当地含税价、上路价、套件价与中国指导价不同，见各条目说明。印度 lakh 已转换为完整数字，大发卡片的 ¥ 为日元。

破产申请、法院受理与宣告破产分别理解，重整计划获批也不等于恢复正常生产。区域合资业务退出不等于全球品牌倒闭。

Logo 来自 [汽车之家车标目录](https://www.autohome.com.cn/car/) 和 [VehicleSpecs 公开车标集](https://github.com/vehiclespecs/brand-logos)，用于品牌识别，相关权利归各权利人所有；历史标志版本可能因年代不同。

## 使用方式

访问在线地址，或下载 `index.html` 用桌面 Chrome、Edge、Safari 等浏览器打开，无需安装依赖或构建。

搜索和筛选同时更新卡片与档案。历史报价勾选框只控制卡片；无可比价格的档案仅在“全部价位”显示。结果计数紧跟勾选说明，以“｜”分隔。目录跳转在必要时会清除冲突筛选。

说明弹窗可通过关闭按钮、弹窗外区域或 Esc 关闭。主题偏好保存在当前浏览器中。

## 交互与维护

主要区域为 `#map`（筛选）、`#tiers`（卡片）、`#archive`（档案）、`#method`（口径）、`#brandDialog`（说明弹窗）。

数据位于 `brands`、`otherArchive` 和 `brandLogos`，分级定义位于 `bands`。`common()` 处理筛选，`card()` 生成卡片，`render()` 更新卡片、档案、目录数量及结果计数，`applyTheme()` 控制主题。起源选项由数据自动生成。

修改资料时核对车型、配置、年份、销售市场、货币和来源；状态需写清涉事主体和事件日期。每轮交付检查桌面布局、筛选、目录、弹窗、主题、Logo 与来源，并同步更新文档计数。

**文件跟踪策略：**按要求跟踪内嵌 Logo 的完整 HTML；反复更换或重新编码素材会增加 Git 历史体积，避免无意义地重复提交导出文件。

GitHub Pages 使用 `main` 分支根目录发布，仓库 About 的 Website 与上方在线地址一致。
