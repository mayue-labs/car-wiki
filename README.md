# 汽车品牌价位图谱

按代表车型与产品布局观察汽车品牌的价位层次，覆盖中国市场常见品牌，并补充少量全球顶级及历史品牌。

**在线访问：[汽车品牌价位图谱](https://mayue-labs.github.io/car-wiki/)** · [GitHub 仓库](https://github.com/mayue-labs/car-wiki)

## 项目概况

面向桌面浏览器的单文件 HTML，包含 82 个品牌 / 业务条目、8 个观察价位档、72 张分级卡片及 18 条历史 / 困境 / 区域退出档案。其中 8 个条目同时出现在分级卡片与历史档案中。

- 从 1,000 万以上到 10 万以下，左侧常驻目录可直达各价位档。
- 支持品牌、英文名、车型搜索，以及经营状态、品牌起源和价位筛选。
- 收录在营、历史破产、破产清算、重整、品牌停用与区域退出等情况。
- 卡片展示品牌 Logo、英文名、国家、代表车型与价格；点击信息图标查看定位与跨档说明，点击价格后的链接图标查看来源。
- 支持浅色、深色、跟随系统，支持返回顶部和打印 / 存为 PDF。
- 文字、数据与 Logo 均已内嵌，可下载后离线使用；打开资料来源需要联网。

## 资料口径

资料整理日期为 **2026-11-14**，页面与交互更新于 **2026-11-15**。内容为精选样本，后续情况请以对应来源最新披露为准。

价位档是编者根据产品布局与代表车型做的观察归类，**不是品牌全系价格上下限，也不是销量加权均价**。同一品牌往往跨多档；卡片上的数字只对应写明的车型、配置与年份。历史价格不与现行报价直接比较。

价格以中国市场人民币万元为主，海外原币报价另行标注。价格通常未计税费、保险、选装等费用；报价年份、配置及特殊计价方式见页面说明。“倒闭”并非统一法律状态，档案分别记录涉事主体、事件范围及来源披露节点。

价格、经营状态等来源可从页面直接回查。Logo 来自 [汽车之家车标目录](https://www.autohome.com.cn/car/) 和 [VehicleSpecs 公开车标集](https://github.com/vehiclespecs/brand-logos)，用于品牌识别，相关权利归各权利人所有；历史品牌的标识版本可能因年代而不同。

## 使用方式

直接访问上方在线地址，或下载 `index.html` 后用桌面 Chrome、Edge、Safari 等浏览器打开，无需安装依赖或构建。

顶部搜索和筛选会同时更新分级卡片与历史档案。历史报价勾选框只控制分级卡片；无可比价格的档案仅在“全部价位”显示。点击左侧目录时，必要时会清除冲突的筛选条件。

点击国家后的信息图标打开说明弹窗，通过关闭按钮、弹窗外区域或 Esc 关闭。主题选择会保存在当前浏览器中。

## 交互与维护

主要区域为 `#map`（筛选）、`#tiers`（分级卡片）、`#archive`（档案）、`#method`（资料口径）及 `#brandDialog`（定位说明弹窗）。

数据位于 `index.html` 内的 `brands`、`otherArchive` 和 `brandLogos`，分级定义位于 `bands`。筛选由 `common()` 处理，卡片由 `card()` 生成，`render()` 同步更新卡片、档案和结果计数。主题由 `applyTheme()` 控制。

修改资料时，应同时核对车型、配置、报价年份、货币单位与来源；经营状态需写清涉事主体和事件日期，避免将区域退出等同于全球品牌倒闭。调整条目后，应同步更新说明中的统计数据。

每次交付需检查桌面布局、筛选、目录、信息弹窗、主题切换及来源链接，并更新本文件与 `CHANGELOG.md`。

**文件跟踪策略：**本仓库按要求跟踪包含内嵌 Logo 的完整 `index.html`，当前约 600 KB。反复更换内嵌素材会增加 Git 历史体积；后续应避免无意义地重新编码素材或重复提交导出文件。

GitHub Pages 使用 `main` 分支根目录发布；仓库 About 中的 Website 与本文件在线地址保持一致。
